**“On leave”** 中文通常是：**休假中 / 请假中 / 休假**

根据语境：

* **I’m on leave.** → 我正在休假。/ 我请假了。
* **She is on annual leave.** → 她正在休年假。
* **He is on sick leave.** → 他正在休病假。
* **I’ll be on leave next week.** → 我下周休假。
* **The manager is currently on leave.** → 经理目前休假中。

### 0.1 常见搭配

* **annual leave** = 年假
* **vacation leave** = 休假
* **sick leave** = 病假
* **maternity leave** = 产假
* **parental leave** = 育儿假
* **leave of absence** = 离职？❌
  → **长期休假 / 暂时离岗**（不是辞职）

注意：**on leave** 不一定是 vacation，也可以是病假、产假等各种正式请假。
